# 席替え・席順くじ

公開 URL: **https://yorozu-craft.com/sekigae/**

教室の席替えと、宴会・飲み会のテーブル席決めを、条件つきのくじで。前回と同じ席を避ける・隣にしない組・前の席の指定、大画面で発表、座席表を印刷。登録なし・無料。
yorozu-craft のツールの1つです（共通ルールは [youheioonuki.github.io の README](https://github.com/YouheiOonuki/youheioonuki.github.io) を参照）。企画書は yorozu-plans の `docs/13_席替え.md`。

## 機能

- 席の並び
  - 教室: 横 1〜12 列 × 前後 1〜10 行、使わない席をタップで「×」、2 人机（2 席ずつ・机のあいだが通路）、教卓を上（生徒から見た向き）／下（先生から見た向き）
  - 宴会: テーブル 20 卓まで、1 卓 1〜16 席、テーブル名。1 卓は向かい合わせの 2 列（奥に半分を切り上げ、手前に残り）
- 名簿: 1 行 1 人の貼り付け（性別は「名前,男」「名前<TAB>女」「名前（女）」など）、または「番号だけ」（名前を入れない）。300 人まで。同じ名前は ②③ を付けて区別
- 座席表で置く（置いてから、残りをくじ）: 席をタップ → 名前を選ぶ（検索つきの listbox）、または席のない人のチップ → 席をタップで、その人をその席に固定（ピン）。ピンの席をタップすると、固定を外す・入れ替える・席を空ける。ドラッグ（マウス。タッチは長押ししてから）かタップ → タップ（「2 人を入れ替える」、席の一覧の「入れ替える」）で入れ替え。ピンは人に付いていく（入れ替えた先でもピン）。「残りをくじで決める」はピンの人を動かさず、残りだけくじで決める。ピン 0 人なら全員をくじで決める（前と同じ席順）
- 組の条件: 2 人を選んで「隣にしない」「隣にしたい」。「隣」の範囲は両方で共通。一覧で見えて ✕ で外す。隣にしたいは必ず守る条件（守れなければ理由を出し、外せば決まる組を名指しする）
- 条件: 前から／後ろから n 番目の並びまで（教室）、前回と同じ席・同じとなりを避ける、男女交互、余った席を後ろにまとめる（教室）
- 決められないときは、どの条件がぶつかっているかを文で出す（数でわかるものは数を、それ以外は「〇〇を外すと決まります」）
- 発表: 全員いっせいに（名前が 1 秒ほど入れかわってから止まる）／1 人ずつ（くじの順・後ろから・前から・名簿の順）。大画面（要素の全画面表示・横向き）、効果音（Web Audio、既定はオフ）
- 結果: くじ番号（10 けた）、2 人を入れ替える（守れなくなった条件を知らせる）、「この席で決定」で記録（10 回分。次の「前回」になる）
- 印刷（A4 横）: 座席表（見出し・日付・教卓）、くじ用紙（席の番号、1 枚 40 枚）。クレジット「yorozu-craft.com/sekigae/print/ で作成」（既定オン・外せる）→ 着地ページ `print/`（noindex・sitemap に載せない）
- 保存: クラス・グループごと（30 個まで）に localStorage（`sekigae_data` ほか、キーはすべて `sekigae_` で始まる）。ファイルへの書き出し・読み込み（D31）
- 共有リンク `#s=`: 既定は席の並びとくじ番号だけ。「名簿と条件・決まった席も入れる」にチェックしたときだけ名前が入る（確認を出す）。番号だけの名簿なら人数・条件・席も入る
- ほかのツールへの導線（README 21）: 宴会のときだけ、結果の下に「当日の精算は → 傾斜割り勘」（値は渡さない）。教室には置かない
- 入力内容はこの端末のブラウザにだけ保存し、外部には送信しない

## 席を決めるしくみ（`calc.js`）

1. くじ番号（seed）から乱数を作る（mulberry32。Math.random は使わない）。同じ seed・席の並び・名簿・条件・前回の記録なら、いつも同じ席順
2. 余った席を先に決める（教室: 後ろの並びから、並びの中はくじ／宴会: 人の多いテーブルから 1 席ずつ減らす）
3. 男女交互がオンなら、となりでつながった席のかたまりごとに男・女の席を 1 つおきに決めておく（固定席の人の性別で向きが決まるかたまりはそれに合わせ、奇数の長さのかたまりの向きで人数に合わせる）
4. 1 人ずつ「座ってよい席」を作る（固定（ピン）・前後の指定・前回と同じ席・男女の席）
5. 座れる席のいちばん少ない人から、くじの順に席を試し、隣にしない組・隣にしたい組（相手がもう座っていれば隣の席だけ、まだなら隣に空いた席が残る席だけ）・前回のとなり・男女交互に反したら戻る（バックトラック）。条件のない人は最後に残りの席へくじで座る。試す回数に上限があり、乱数の流れを変えて 8 回までやり直す
6. 見つからなければ、条件を 1 種類ずつ外して解けるかを試し、外せば決まる条件を返す。組の条件なら、さらに 1 組ずつ外して、外せば決まる組を返す（先頭 30 組まで）

解く前に数でわかる矛盾: 前（後ろ）の席の数、隣にしない 2 人がどちらも隣り合うピン、隣にしたい 2 人がどちらも隣でないピン、隣にしたい相手が隣の席の数より多い、男女の人数。

### 保存データの形（条件）

`cons = { pins: [{p, seat}], zone, pairs: [{a, b, type: 'ng'|'want'}], ngScope, avoidSeat, avoidNeighbor, gender, emptyBack }`。変更前の形（`fixed`: 固定席の行、`ng`: `[[名前, 名前]]`）は、保存データ・バックアップ・共有リンクを読むときに `normalizeCons` が `pins`・`pairs`（type `ng`）へ移す。共有リンクには、名前を入れるときだけピンと組が入る（番号だけの名簿は従来どおり）。

### 「隣」の定義

| 範囲 | 教室 | 宴会 |
|---|---|---|
| となり（`side`） | 同じ横の並びで左右に接する席。2 人机は同じ机の相手だけ（通路をはさむと数えない） | 同じテーブルの同じ側で左右に接する席 |
| 前後左右（`cross`） | となり＋通路をはさんだ左右＋すぐ前・すぐ後ろ | となり＋真向かい |
| まわり（`around`） | 前後左右＋ななめ（周りの 8 席） | 前後左右＋ななめ向かい |
| 同じテーブル（`table`） | （まわりと同じ） | 同じテーブル |

使わない席（×）をはさんだ 2 席は隣ではない。「前回と同じとなり」と「男女交互」は `side` で判定する。隣にしない組・隣にしたい組は、選んだ範囲で判定する。

## 文言

JavaScript から出す文（理由・お知らせ・ボタンの切り替え・ラベルなど）は `text.js` の `TEXT` に集めている。`calc.js` は文を持たず `{ code, ... }` を返す。HTML に直接書いた文は HTML のまま。別の言語の版を作るときは `TEXT` を差し替える。

## 保守

時点のある値（制度・料率など）は持たない。定期の見直しは不要。

直したら、`guide.html` の「更新履歴」に日付と内容を 1 行足す。
